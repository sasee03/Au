# AURUM Quick Start for New Developer

## First Time Setup (5 minutes)
```bash

cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --port 4000 --reload          

# Frontend
cd ..\frontend
npm install
```

## The 7-Step Data Pipeline
1. **DataConnectorsPage** → Upload CSV or connect Postgres
   - Stores: `aurum_base_name`, `aurum_bronze_table`, `aurum_source`
   
2. **DatasetExplorerPage** (Postgres only) → Select tables
   - Stores: `aurum_selected_tables`
   
3. **PipelineConfigPage** → Confirm & create run
   
4. **BronzeLayerPage** → View raw data
   - Loads from: `GET /api/bronze/list` & `GET /api/bronze/preview`
   - Stores: `aurum_bronze_schema`
   
5. **SilverValidationPage** → Write cleaning rules
   - `POST /api/silver/generate-sql` → AI writes SQL (or fallback)
   - `POST /api/silver/execute` → Runs CTE pipeline, creates silver table
   - Stores: `aurum_silver_result`
   
6. **GoldLayerPage** → Define KPIs
   - `POST /api/gold/generate-kpi` → AI decomposes requirement
   - `POST /api/gold/execute` → Creates gold KPI tables
   - Stores: `aurum_gold_result`
   
7. **ReportPage** → Display final results

## Table Naming (CRITICAL — use `naming.py` functions!)
```python
# Given: customer_orders.csv
base_name = "customer_orders"

bronze."customer_orders_bronze"
silver."customer_orders_silver"  
gold."customer_orders_gold_total_revenue"
gold."customer_orders_gold_top_customers"
# etc.
```

**Never construct manually — use:**
```python
from app.services.naming import make_base_name, bronze_table, silver_table, gold_table

base = make_base_name("customer_orders.csv")  # → "customer_orders"
bronze_table(base)   # → "customer_orders_bronze"
silver_table(base)   # → "customer_orders_silver"
gold_table(base, "Total Revenue")  # → "customer_orders_gold_total_revenue"
```

## Key Files to Know
| File | What It Does |
|---|---|
| `app/services/naming.py` | All table naming logic — core of platform |
| `app/services/bronze_service.py` | CSV upload + Postgres ingest |
| `app/services/silver_service.py` | SQL generation + execution |
| `app/services/gold_service.py` | KPI generation + execution |
| `app/prompts/silver_prompt.py` | Tune this to improve SQL generation |
| `app/prompts/gold_prompt.py` | Tune this to improve KPI suggestions |
| `frontend/src/pages/SilverValidationPage.jsx` | Where cleaning rules become SQL |
| `frontend/src/pages/GoldLayerPage.jsx` | Where requirements become KPIs |

## Most Common Next Steps
1. **Improve SQL generation** → Edit `app/prompts/silver_prompt.py`
2. **Improve KPI detection** → Edit `app/prompts/gold_prompt.py`
3. **Add new data source** → Add new route in `app/routes/` + service
4. **Add validation rules** → Extend `SilverValidationPage.jsx` + `silver_service.py`
5. **Add real-time preview** → Stream rows from `GET /api/bronze/preview`

## Architecture at a Glance
```
User Browser
    ↓
React SPA (frontend/)
    ↓ (sessionStorage for state)
FastAPI Routes (app/routes/)
    ↓
Services (app/services/)
    ↓ (naming.py ensures consistent table names)
PostgreSQL (aurum database)
    ├── bronze.* (raw data)
    ├── silver.* (cleaned data)
    └── gold.* (KPI tables)
```
